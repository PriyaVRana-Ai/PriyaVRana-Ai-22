# PriyaVRana-Ai 🙏

PriyaVRana-Ai is a royal blue AI assistant with a clean white sidebar.

## Features

- AI Chat
- Shayari AI
- Song AI
- Study AI
- Comedy AI
- Image AI
- Voice AI
- Chat history
- Responsive mobile design
- Royal blue interface
- "Radhe Radhe" welcome experience

## AI Services

- Groq for text-based AI
- Stability AI for image generation

## Environment Variables

Add these variables in Vercel:

GROQ_API_KEY=your_groq_key_here

STABILITY_API_KEY=your_stability_key_here

Never put real API keys inside GitHub source files.

## Development

Install dependencies:

npm install

Run the development server:

npm run dev

Then open:

http://localhost:3000
